Find GitHub repositories via the GitHub REST search API

Usage: wit <search|s> [OPTIONS]

Options:
      --ignore <PATH|GLOB>  Exclude files, directories, or glob patterns (repeatable)
  -p, --pattern <PATTERN>   Optional repository name filter. GitHub treats this as a literal name search, not regex
  -l, --lang <LANG>         Optional GitHub language qualifier
  -q, --query <QUERY>       Additional raw GitHub search terms and qualifiers, passed through as-is
  -n, --limit <LIMIT>       Maximum number of repositories to print (GitHub search caps at 1000) [default: 10]
  -h, --help                Print help

Use -p/--pattern to restrict repository names and -q/--query to pass raw GitHub search terms and qualifiers through to the REST API. Common qualifiers include language:, user:, org:, stars:, forks:, size:, created:, pushed:, topic:, archived:, mirror:, template:, license:, help-wanted-issues:, and good-first-issues:.

wit fetches only enough GitHub pages to satisfy --limit (default: 10, max: 1000). Results are ordered by stars. GitHub repository search does not support regex name matching; --pattern is treated as a literal name filter.

Set GITHUB_TOKEN for higher GitHub rate limits.

Examples:
  wit search -p 'ratatui' -l 'Rust' --limit 20
  wit search -q 'stars:>1000 topic:tui archived:false' --limit 25
  wit search -p 'auth' -q 'user:ory language:Go pushed:>2025-01-01'
