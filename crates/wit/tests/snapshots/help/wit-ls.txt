List directory contents (non-recursive). Use -l for file sizes

Usage: wit ls [OPTIONS] [REPO] [PATH]

Arguments:
  [REPO|PATH]...  Repository and optional path: `owner/repo [path]`, or just `[path]` when using -r/--repo

Options:
      --ignore <PATH|GLOB>     Exclude files, directories, or glob patterns (repeatable)
  -r, --repo <REPO>            Repository in "owner/repo" format
      --branch <BRANCH>        Branch name under refs/heads to read instead of the repository default branch
      --refresh-cache          Refill the disk cache for the branch before reading (cloud pack, else GitHub clone); ignored with --backend memory
  -l, --long                   Show file sizes: lines and approximate token count
      --backend <disk|memory>  Snapshot backend: disk (default; local bare-repo cache filled from the shared cloud pack cache, else a GitHub clone) or memory (GitHub API into RAM, no disk writes). Overrides WIT_SNAPSHOT_BACKEND
  -h, --help                   Print help

Use to browse one directory level at a time. Unlike tree (recursive), ls shows only immediate children. Use -l to see line counts and token estimates before deciding what to read.

Pass the repository as a positional `owner/repo` or with -r/--repo. If both are given they must match.

Examples:
  wit ls ratatui/ratatui
  wit ls ratatui/ratatui src/widgets
  wit ls -r ratatui/ratatui src
  wit ls -l ratatui/ratatui src
  wit ls ratatui/ratatui --backend memory
