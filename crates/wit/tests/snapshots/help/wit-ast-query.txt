Run a tree-sitter S-expression query and print every capture

Usage: wit ast query [OPTIONS] <QUERY> [REPO] [PATH]

Arguments:
  <QUERY>         tree-sitter query, e.g. '(function_item name: (identifier) @name)'
  [REPO|PATH]...  Repository and optional file or directory: `owner/repo [path]`, or just `[path]` when using -r/--repo

Options:
      --hostname <HOSTNAME>    GitHub hostname (--hostname > GH_HOST > GITHUB_HOST > github.com)
  -r, --repo <REPO>            Repository in "owner/repo" format
      --ignore <PATH|GLOB>     Exclude files, directories, or glob patterns (repeatable)
      --ref <REF>              Branch, tag, or full commit SHA to read (default: the repository default branch) [aliases: --branch]
      --refresh-cache          Refill the disk cache for the branch before reading (cloud pack, else GitHub clone); ignored with --backend memory
      --lang <LANG>            Language the query is written for (required unless PATH is a single source file)
  -g, --glob <GLOB>            Glob pattern to filter files (e.g., "*.rs", "src/**")
      --max-files <MAX_FILES>  Maximum files to parse (default: 500) [default: 500]
      --json                   Emit JSON instead of plaintext
      --backend <disk|memory>  Snapshot backend: disk (default; local bare-repo cache filled from the shared cloud pack cache, else a GitHub clone) or memory (GitHub API into RAM, no disk writes). Overrides WIT_SNAPSHOT_BACKEND
  -h, --help                   Print help
