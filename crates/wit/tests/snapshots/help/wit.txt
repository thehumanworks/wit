Explore GitHub repositories without cloning. Reads come from a local shallow bare-repo cache (the default disk backend) or from the GitHub API into RAM (--backend memory).

Usage: wit [OPTIONS] <COMMAND>

Commands:
  search    Find GitHub repositories via the GitHub REST search API [aliases: s]
  branches  List remote branches with default-branch comparison metadata
  cache     Refill the disk cache (cloud pack, else GitHub clone) or pin a memory snapshot [aliases: c]
  tree      Show the file tree of a repository (or subtree). Use -l for line counts [aliases: t]
  ls        List directory contents (non-recursive). Use -l for file sizes
  cat       Print a file's contents. Use -n for line numbers
  rg        Search file contents (ripgrep-style). Use -l to find files, -g to filter by type
  sed       Extract or transform file content using sed scripts (POSIX-style, Rust regex)
  head      Print the first N lines of a file (default: 10)
  tail      Print the last N lines of a file, or from line N onward
  ast       AST-backed search: list definitions or run tree-sitter queries
  skill     Manage the wit agent skill
  mcp       Start wit MCP (direct by default; Code Mode experimental)
  help      Print this message or the help of the given subcommand(s)

Options:
      --hostname <HOSTNAME>  GitHub hostname (--hostname > GH_HOST > GITHUB_HOST > github.com)
      --ignore <PATH|GLOB>   Exclude files, directories, or glob patterns (repeatable)
  -h, --help                 Print help
  -V, --version              Print version

Start here:
  wit rg -n 'fn main' owner/repo                       search contents; prints path:line:text
  wit cat -n --lines 80-140 owner/repo src/main.rs      read a line range with its line numbers
  wit head -n 60 owner/repo/README.md                   read the start of a file
  wit tree owner/repo src                               list files under a directory
  wit cat owner/repo Cargo.toml                         print a whole file, only when you need all of it

Search first, then read ranges: rg -n gives line numbers and cat -n --lines START-END reads around them with the same numbers, so cite the numbers you see. cat prints at most 500 lines unless you pass --full. sed, head, and tail work like their POSIX versions.

Pass the repository as owner/repo, -r owner/repo, or owner/repo/PATH. Pass --ref REF to read a branch, tag, or full commit SHA (default: the repository default branch). Each read prints `snapshot: ... commit=SHA` on stderr; cite that commit, and pass --ref SHA to read the same commit again.

Find repositories with wit search -p NAME. List branches with wit branches owner/repo. Backends, the disk cache, and the shared cloud cache: wit cache --help.
